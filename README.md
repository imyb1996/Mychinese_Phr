# التدرب على الجمل الصينية

صفحة واحدة (`index.html`) لعرض الجمل الصينية والتدرب عليها، وتقرأ جملها مباشرة من ملفين على Google Sheets:

- **جمل المصنع**: مستوى ومجموعة.
- **Little Fox**: مستوى ومجموعة ودرس.

## المزايا

- فلترة بالمستوى والمجموعة والدرس، وبحث بالعربي أو البينين أو الصيني.
- استبعاد جمل من الطباعة، وتحديد جمل بعينها.
- تغيير حجم الخط في العرض والطباعة مع معاينة، وطباعة A4 أو A5 مع ترقيم الصفحات.
- زر «تحديث» لجلب آخر تعديلات الشيت، ونسخة محفوظة تظهر عند انقطاع الاتصال.

## التشغيل

افتح `index.html` في المتصفح (Chrome أو Edge)، أو من رابط GitHub Pages إذا فعّلته.

> يجب أن يكون الشيتان مشاركين بخيار «أي شخص لديه الرابط» لتظهر آخر التعديلات؛ وإلا تُعرض النسخة المحفوظة داخل الصفحة.
